Data Flow

  • Client → Server: Next.js pages fetch data server-side (no hydration mismatch)
  • Server → DB: Supabase PostgREST for CRUD, RLS enforces row-level access
  • Auth Flow: Supabase Auth (JWT) → SessionProvider (React context) → Sidebar (permission filtering)
  • Permissions: RBAC roles (admin, PM, sales, employee, accountant) with fine-grained grants
